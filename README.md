# スカイライン・テクノロジーズ 企業サイト

スカイライン・テクノロジーズ株式会社のコーポレートサイトです。
業務システム開発・クラウド基盤構築・Web／モバイルアプリ・保守運用を一貫して手がけるソフトウェア開発会社として、事業内容や実績を紹介します。

## サイトの構成

`index.html` 1ファイルで構成された1ページのサイトです。ページ内には次のセクションがあります。

| セクション | 内容 |
| --- | --- |
| お知らせ | プレスリリース・採用・認証などの最新情報 |
| トップ（ヒーロー） | キャッチコピー、会社紹介、主要な数字（累計プロジェクト数など） |
| 事業内容 | 業務システム開発／クラウド基盤構築／Web・モバイルアプリ／保守・運用 |
| 導入実績 | 物流・金融・小売の事例と成果 |
| 開発の進め方 | ヒアリングから運用・改善までの5ステップ |
| 会社概要 | 商号、設立、所在地、認証など |
| 採用 | 募集中の職種 |
| お問い合わせ | 問い合わせフォーム |

CSS と JavaScript は `index.html` の中に直接書かれています。ビルドやインストールは不要です。
フォントは Google Fonts から読み込みます（オフラインの場合は代替フォントで表示されます）。

## ブラウザで表示する手順

### 方法1：ファイルをダブルクリックする（いちばん簡単）

1. Finder でこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Safari、Chrome など）でサイトが表示されます。

ブラウザを指定したい場合は、`index.html` を右クリック →「このアプリケーションで開く」から選びます。
ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

### 方法2：ターミナルから開く

```sh
cd ~/Desktop/company-site
open index.html
```

Chrome で開く場合：

```sh
open -a "Google Chrome" index.html
```

### 方法3：ローカルサーバーで表示する（任意）

実際の Web サーバーに近い環境で確認したい場合は、Mac に標準で入っている Python で簡易サーバーを起動できます。

```sh
cd ~/Desktop/company-site
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開くと表示されます。終了するときはターミナルで `Ctrl + C` を押します。

## 編集したあとの確認

`index.html` を保存したら、ブラウザで再読み込み（Mac は `Cmd + R`）すると変更が反映されます。
